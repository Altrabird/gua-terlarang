# Gua Terlarang

Permainan roguelite pelayar yang asli dari Malaysia: pilih wira daripada cerita rakyat Melayu, turun ke lapan
tingkat Gua Terlarang dalam pertarungan automatik berdadu d20, dan patahkan sumpah Sang Kelembai.

**Main sekarang:** https://Altrabird.github.io/gua-terlarang/

Boleh dimainkan pada komputer, telefon dan tablet (pegang secara melintang). Lihat CREDITS.md untuk sumber seni dan lesen.

# Credits

**Gua Terlarang** is an original game. Its heroes, monsters and places are our own designs inspired by Malay
folklore (toyol, pelesit, langsuir, orang minyak, hantu raya, orang bunian, Sang Kelembai), which is public heritage.
No art, names, numbers or code from any other game are used.
